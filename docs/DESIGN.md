# 设计思路 —— 赛道二·基于深度学习的三维点云降噪

适用权重：`checkpoints/aboard_best_swa19_bnfix.pkl`（A 榜提交所用）

**方案概述**：以 CVPR 2024 论文 PD-LTS（Mao et al., *Denoising Point Clouds in Latent Space via Graph Convolution and Invertible Neural Network*）的"图卷积特征 + 可逆网络隐空间去噪"为参考架构，**全部用 Jittor 实现并从零训练**（不加载任何预训练/PyTorch 权重，不使用任何外部数据）。最终提交是**一份权重、单次前向**的单模型，无任何模型融合。方案由五个部分构成：网络结构（§2）、可逆求逆的反传设计（§3）、数据与损失（§4）、训练调度与权重平均（§5）、推理（§6）。各设计点均附消融依据。

---

## 1. 任务分析：分数的构成决定设计

评分 = 0.5×CD + 0.5×P2S（相对噪声输入的改善率）。我们把 CD 拆解为 forward（预测→真值，衡量**贴面精度**）与 backward（真值→预测，衡量**覆盖/排布均匀性**），用稠密真值做 oracle 测量后得到两条支配设计的结论：

1. **贴面与排布必须同时优化**。同样精确落在曲面上的 50k 点，均匀排布比随机排布的 backward 低约 37%。因此损失中的排布项（repulsion / Sinkhorn）不是正则化装饰，而是直接服务于 CD-backward 的主力项（§4 消融佐证）。
2. **精度上限由残余离面距离决定**。模型收敛后输出点的排布统计已接近理想均匀（最近邻间距的均值与变异系数几乎与理想蓝噪声一致），剩余误差集中于 ~0.002（单位球坐标）的残余离面距离，且该误差无偏、空间弱相关。据此我们**不设计任何后处理**（局部曲面拟合投影在薄壁形状上因法向估计失效而恶化结果，实测判负），把全部精度预算放在网络本身（§5 的 patch 尺度对齐与权重平均即为此服务）。

## 2. 网络结构（`src/pdlts_jittor/pdlts_model.py`，纯 Jittor）

- **特征提取**：EdgeConv 图卷积堆叠（KNN 图，消息 `[x_j, x_j−x_i]`，feature_hidden=64）。
- **去噪主体**：谱归一化（induced-norm，Lipschitz 系数 0.98）线性层构成的可逆残差流块。去噪过程 = 隐空间变换后**定点迭代求逆**回坐标空间；谱归一化（`src/pdlts_jittor/train/spectral.py`，幂迭代维护）保证收缩性，是求逆收敛的前提。

## 3. 可逆求逆的反传设计：K=2 截断 Neumann

定点求逆的反传需近似 `(I+G')⁻¹`。我们对截断阶数 K 做了与全展开真梯度的保真度测量：

| K | cos(g, g_full) | 梯度符号错误率 |
|---|---|---|
| 1 | 0.058 | 40.9% |
| **2（采用）** | **0.873** | **12.1%** |
| 3–6 | 0.86–0.89 | 11–14%（无进一步收益） |

K=1 的梯度接近随机方向，网络虽能收敛但精度上限低；K=2 已恢复绝大部分梯度方向，且因残差按 0.98^K 衰减，K>2 无增益、只多耗显存。故训练固定 `FP_GRAD_ITERS=2`。这是本方案精度上限的**必要条件**。

## 4. 数据与损失

**数据**（`src/pdlts_jittor/train/data.py`，仅官方 dataset_train）：官方 15833 个网格中，**151 个划为本地验证并整体从训练集剔除**（清单 `tools/heldout_151.txt`），其余 **15682 个全部采样成功**用于训练（`tools/prepare_train_npy.py` 从官方网格一键重建，面积加权均匀表面采样 50k 点/模型），训练∩验证 = 0。
在线增广：逐点 Laplace 噪声 `b∈U[0.004,0.017]` → RandomScale[0.8,1.2] → 三轴随机旋转 → 以噪声点为种子 KNN 取 patch。

**损失**（`src/pdlts_jittor/train/losses_jt.py` / `src/pdlts_jittor/train/emd_jt.py`，单位球归一化坐标）：

`L = 0.10×EMD(512点子集, inverse_fraction缩放) + 40×CD + 40×repulsion(r0=0.05) + 40×Sinkhorn(eps=0.005, iters=30)`

- EMD/CD 负责贴面（forward 侧），repulsion/Sinkhorn 负责排布（backward 侧），与 §1 的分数拆解一一对应。
- 配比消融（同基线单变量，本地验证分）：删 repulsion → 持平偏负；删 Sinkhorn 并提高 EMD → **−0.15**（P2S 几乎不动而 CD 明显掉）——证明排布项在挣 CD-backward 的分。
- 我们也验证过再加"逐点配对 L2"监督（数据里噪声/干净点天然同索引配对）：**不涨反跌**（权重越大越差，−0.22~−1.31），残余离面误差对监督形式免疫——这支持了 §1 结论 2，也说明当前损失组合已在监督层面饱和。

## 5. 训练调度与权重平均（单一轨迹）

| 阶段 | epoch | train patch | emd_w | 其余 |
|---|---|---|---|---|
| S1 | 1–78 | 1024 | 0.10 | lr=2e-4 常数，Adam，bs=4，clip_grad_norm 1e-3，每步幂迭代更新谱 scale |
| S2 | 79–97 | **2048** | **0.05** | 其余同 S1 |

- **训练/推理 patch 尺度对齐（S2 的设计动机）**：推理在大 patch 上进行，若训练只见过 1024 点的局部上下文，网络在推理尺度下欠拟合。将训练 patch 提到 2048 后，残余离面 rms 由 0.00289 降至 0.00282——是我们全部对照实验中**唯一显著降低该瓶颈量**的手段（对照：改损失配比、加配对监督、单纯延长训练均无效）。注意 `emd_subset_scale=num_points/512` 随 patch 翻倍会被动放大 EMD 权重，emd_w 由 0.10 减半到 0.05 抵消，保持损失配比不变。
- **宽窗口 SWA**（`src/pdlts_jittor/train/make_swa_ckpt.py`）：对 S2 的 **ep79–97 共 19 个 checkpoint 做权重平均**。窗口宽度消融（本地验证分）：3/7/10/13/19 点 = 82.33/82.47/82.57/82.62/**82.69**，单调上升且未饱和——平均窗口内更多的点比单点"更晚的 checkpoint"更有价值（单独延长训练不加宽窗口：负收益）。
- **平均后的两步修正**（`src/pdlts_jittor/train/bn_recalibrate.py`，必不可少）：
  1) **谱 scale 重算**：谱范数是凸函数，`mean σ(Wᵢ) ≥ σ(W_avg)`，存储 scale 的平均值系统性偏大，须在平均权重上重新幂迭代；
  2) **BN 统计量重估**（SWA 原论文要求）：重置 running mean/var，在训练数据上以 patch=2048 前向 120 个 batch 重估。实测同一权重 train/eval 模式的输出差可达位移量级的 28–34%，此步直接影响成绩。
- **不做输出融合**：多模型/多 patch 划分的输出逐点平均在本任务判负（平均会破坏 §1 所述的均匀排布，backward 变差抵消收益）。权重平均（SWA）不经过输出空间，无此问题——这是选择 SWA 而非 ensemble 的原因。

## 6. 推理（`run_heldout_strict_jittor.py` / `strict_jittor_denoise.py`）

单位球归一化 → FPS 选种子 → KNN 取 patch（**3072** 点）→ 网络预测位移 → 逐点按最近 patch（argmax）归属融合 → 共 **2** 轮迭代 → 反归一化输出（点数与输入严格一致，float32）。

推理参数由本地 151 形状验证集扫描确定（本地分）：

| 参数 | 扫描 | 采用 | 依据 |
|---|---|---|---|
| patch_size | 1024/2048/3072/4096 = 82.05/82.27/82.33/82.33 | **3072** | ≈1.5×训练patch 处最优后饱和 |
| seed_k | 4/6/9 = 82.43/82.47/82.48 | **6** | 差异在噪声内，取居中省时 |
| niters | 2 vs 3 = 82.47 vs 81.58 | **2** | 3 轮开始过度平滑（P2S 掉） |

## 7. 合规性自查

- **框架**：训练与推理全链路纯 Jittor 1.3.10（本仓库所有 `.py` 无任何 `torch` 依赖，`grep -rn "import torch" src/` 为空）；checkpoint 为 `jt.save` 的 `.pkl`。
- **数据**：仅官方 dataset_train / dataset_test_noisy。训练 npy 全部可由 `tools/prepare_train_npy.py` 从官方网格重建（核验：训练所用 15682 个形状 ID 全部 ⊂ 官方训练集）。无外部数据集、未使用参考论文的数据。
- **权重**：随机初始化从零训练；参考论文的开源 PyTorch 权重从未加载或转换进本方案。
- **输出**：点数与输入逐模型严格一致、float32、目录结构合规（`tools/package_result.py` 内置全部硬校验）。
- **算力参考**（单卡 RTX 4090 24G）：S1 78ep×2.7h + S2 19ep×3.2h ≈ 270 GPU·h；SWA+BN 约 0.5h；测试集推理单卡约 5.5h（支持多卡分片）。
